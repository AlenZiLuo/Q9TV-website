01节目概述

编写人：2025级负责人 李奕鸣 适用对象：校园电视台全体成员

影音大课堂是校园电视台的常规播放节目，时长约 15 分钟 （上下浮动 3 分钟，即 12–18 分钟均可）。播放时间为每周周二和周四。

节目包含以下三类内容：

类型一

新闻合集

从 CCTV 新闻联播中挑选、剪辑新闻片段合集。
素材来源：CCTV（通过 cctvdl 下载）

类型二

模范榜样

展示先进人物事迹的专题节目。
素材来源：CCTV 面对面、感动中国等

类型三

科普短片

高质量科普类视频。
素材来源：Bilibili 平台

02素材获取方式

2.1 CCTV 视频下载（新闻合集 / 模范榜样）

使用 cctvdl 工具进行下载。 项目地址：https://github.com/POI-WX/cctvdl。 详细操作方法请参阅该项目的 README 文档。

【新闻合集制作要求】

  1. 素材范围：截取上一次新闻播放日至本次播放日之间所有新闻联播视频。
  2. 内容选取标准：CCTV 正式播出的内容均可选取。注意不重复，确保内容全面、充分、最新。
  3. 剪辑逻辑：按照新闻联播节目的传统编排顺序——国内新闻 → 国际新闻， 保持合理的叙事节奏与逻辑连贯性。

【模范榜样制作要求】

  • 可从 CCTV 下载「面对面」「感动中国」等介绍模范人物的节目。
  • 栏目不限于上述两类，可根据实际需要灵活扩展。

2.2 Bilibili 视频下载（科普短片）

使用以下工具从 Bilibili 平台下载视频：

  • DownKyi（哔哩下载姬）—— 推荐
  • 唧唧Down —— 备选

【科普短片推荐方向】

  • 「星球研究所」等高质量地理/人文科普账号
  • 其他制作精良、内容准确的科普视频
注意事项：Bilibili 视频自带平台水印，无需额外标注来源。 确保选取的视频无版权争议风险。

03剪辑与时长控制

  • 可裁剪：允许裁掉冗余片段，但不得修改原意。
  • 时长不足：可将多个视频合并为合集。
  • 时长超出：可按内容分为上下集播放。
  • 目标时长：12–18 分钟为宜。

04校园电视台网络配置

校园电视台备有一台网络交换机，通过 RJ45 接口网线连接互联网。 使用时需手动配置网络参数。

4.3 以太网手动设置步骤（Windows）

  1. 打开 设置 → 网络和 Internet → 以太网。
  2. 点击当前连接的以太网适配器。
  3. 找到 IP 设置，点击编辑。
  4. 将自动（DHCP）切换为手动。
  5. 开启 IPv4，按上表填入对应设备的 IP 地址、子网前缀长度、网关及 DNS。
  6. 保存并确认连接成功。

05数据备份规范

采用本地多备份 + 百度网盘云备份的双重备份策略：

  • 本地备份：建议至少在两个不同的物理存储设备上保存副本 （如电脑硬盘 + 移动硬盘/U 盘）。
  • 云端备份：上传至百度网盘，确保素材和成品均有留存。
  • 每次制作完成后及时备份，避免数据丢失。

06设备使用守则

  1. 爱护设备 —— 轻拿轻放，规范操作。
  2. 禁止饮食 —— 不携带食品、饮品进入电视台。
  3. 数据安全 —— 制作完成后及时备份和保存。
  4. 离开前检查：
    关闭电脑 关闭相机 关闭灯光 关闭空调 确认门窗关好
